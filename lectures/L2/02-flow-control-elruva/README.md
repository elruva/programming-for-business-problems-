# Session 2: Flow Control

Learn how to control program flow with Boolean conditions, selection (if/elif/else), and iteration (loops).

## Folders

| Folder | Topic | Description |
|--------|-------|-------------|
| `01_Boolean_Conditions` | Boolean Logic | Comparison and logical operators (`==`, `!=`, `and`, `or`) |
| `02_Selection` | Selection | Make decisions with `if`, `elif`, and `else` |
| `03_Iteration` | Loops | Repeat code with `while` and `for` loops |

Each folder ends with `modify` and/or `make` exercises that apply the concept.

Start with `01_Boolean_Conditions` and work through the folders in order.
