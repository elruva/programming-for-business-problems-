# 02 - Selection

Learn how to make decisions in your code using `if`, `elif`, and `else`.

## Key Concepts

- **`if`** - executes code when condition is `True`
- **`else`** - executes code when condition is `False`
- **`elif`** - adds additional conditions
- **Indentation** is required for code blocks
- Only **one branch** executes in an `if`/`elif`/`else` chain

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- Selection begins with `if`, has as many `elif`s as needed, and ends with `else`
- A colon (`:`) at the end of each `if`, `elif`, and `else` line
- Each branch is indented (4 spaces)
- `if`, `elif`, and `else` are **not** indented
- A condition after each `if` and `elif`
- No condition after `else`
- Double equals (`==`) in conditions when checking equality
