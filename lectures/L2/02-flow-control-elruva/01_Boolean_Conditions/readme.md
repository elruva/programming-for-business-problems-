# 01 - Boolean Conditions

Learn how to evaluate conditions using Boolean operators.

## Exercises

| File | Type | Description |
|------|------|-------------|
| `01_predict.py` | Predict | Basic comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) |
| `02_predict.py` | Predict | Complex expressions with `and`, `or`, `not` |
| `03_investigate.py` | Investigate | Analyze and answer questions about a thesis-check condition |
| `04_modify.py` | Modify | Extend the thesis check with additional requirements |
| `05_make.py` | Make | Build a leap year checker using only Boolean expressions |

## Key Concepts

- **Comparison operators**: `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Logical operators**: `and`, `or`, `not`
- **Boolean values**: `True` and `False`
- **String comparisons** are case-sensitive!

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- You only compare variables of the same data type
- You use double equals (`==`) when checking if two pieces of data are the same
- Single equals (`=`) is for assignment, double equals (`==`) is for comparison
