## Key Concepts

- **`while` loop** - repeats while condition is `True` (indefinite iteration)
- **`for` loop** - iterates over a sequence (definite iteration)
- **Iteration variable** - controls how many times the loop runs
- **`range(n)`** - generates numbers from 0 to n-1
- **`break`** - exits the loop immediately
- **`continue`** - skips to the next iteration

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- `while` loops need a condition that eventually becomes `False`
- `for` loops need something to iterate over (list, range, string, etc.)
- A colon (`:`) at the end of the `while`/`for` line
- All code to repeat is indented
- Code after the loop is **not** indented
- Always update your iteration variable to avoid infinite loops!
