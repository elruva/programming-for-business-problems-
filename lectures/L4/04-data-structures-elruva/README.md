# Session 4: Data Structures

Learn how to work with collections of data using lists, dictionaries, string methods, and files.

## Folders

| Folder | Topic | Description |
|--------|-------|-------------|
| `01_Lists` | Lists | Store and manipulate ordered sequences of items |
| `02_Dictionaries` | Dictionaries | Store data as key-value pairs |
| `03_StringMethods` | String Methods | Clean and transform text data |
| `04_Files` | Files | Read from and write to files |

Each folder ends with `modify` and/or `make` exercises that apply the concept.

Start with `01_Lists` and work through the folders in order.
