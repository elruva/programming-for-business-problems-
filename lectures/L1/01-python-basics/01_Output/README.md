# 01 - Output

Learn how to display text and numbers using Python's `print()` function.

## Exercises

| File | Type | Description |
|------|------|-------------|
| `01_predict.py` | Predict | Simple print() statement with "Hello, World!" |
| `02_predict.py` | Predict | Multiple print() statements with text and numbers |
| `03_investigate.py` | Investigate | Find and fix a capital letter error |
| `04_investigate.py` | Investigate | Find and fix a missing quotation mark |
| `05_investigate.py` | Investigate | Find and fix missing quotes around a string |
| `06_modify.py` | Modify | Write your own print statements (name, favorite number) |
| `07_make.py` | Make | Print a multi-line joke using `\n` |

## Key Concepts

- **`print()`** - displays output to the console
- **Strings** - text in quotation marks (`"Hello"` or `'Hello'`)
- **Numbers** - integers and decimals don't need quotes
- **Syntax** - Python is case-sensitive (`print` not `Print`)

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- `print` does not have a capital letter
- Text (strings) is surrounded with quotation marks
- Everything inside `print()` is enclosed in parentheses
- Opening and closing quotes must match
