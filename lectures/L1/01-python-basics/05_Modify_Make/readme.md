# 05 - Modify & Make

Apply all basics concepts to create complete programs.

## Exercises

| File | Type | Description |
|------|------|-------------|
| `01_modify.py` | Modify | Improve a greeting program with input and f-strings |
| `02_modify.py` | Modify | Fix and extend a buggy calculator |
| `03_make.py` | Make | Create a rectangle area calculator |
| `04_make.py` | Make | Build a restaurant tip calculator |

## Skills Combined

These exercises combine:
- **Output** using `print()` and f-strings
- **Variables** to store and reuse data
- **Input** to get data from users
- **Math** operations and type conversion

## Tips

- Start simple, then add features one at a time
- Test your code after each change
- Use f-strings for clean, readable output
- Remember: `input()` returns strings - convert with `int()` or `float()`
- Use `.2f` in f-strings to format currency: `f"${price:.2f}"`
