# Session 1: Python Basics

Learn the fundamentals of Python programming: output, variables, input, and math.

## Folders

| Folder | Topic | Description |
|--------|-------|-------------|
| `01_Output` | Output | Display text with `print()` |
| `02_Variables` | Variables | Store data with variables and f-strings |
| `03_Input` | Input | Get user input with `input()` |
| `04_Math` | Math | Arithmetic operators and type conversion |
| `05_Modify_Make` | Combined | Apply all concepts together |

Start with `01_Output` and work through the folders in order.
