# 02 - Variables

Learn how to store and manipulate data using variables.

| File | Type | Description |

| `02_predict.py` | Predict | Multiple variables and f-strings |

## Key Concepts

- **Variables** - named containers that store data
- **Assignment** - using `=` to store a value in a variable
- **Data types** - `int` (integers), `float` (decimals), `str` (strings)
- **f-strings** - formatted strings with embedded variables: `f"Hello {name}"`
- **String slicing** - extracting parts of a string: `text[0:5]`

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- Variable names cannot start with a number
- Variable names cannot contain spaces (use underscores: `my_variable`)
- Python is case-sensitive (`Name` and `name` are different variables)
- f-strings must start with `f` before the opening quote
