Learn how to define and call functions in Python.

## Key Concepts

- **`def`** - keyword to define a function
- **Function name** - follows same rules as variables (lowercase, underscores)
- **Function body** - indented code that runs when function is called
- **Calling a function** - use the function name followed by parentheses
- **Execution order** - code runs top to bottom, but function body only runs when called

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- Function must be defined before it is called
- Function name is followed by parentheses `()` when calling
- The function body is indented (4 spaces)
- `def` ends with a colon `:`
- Function names cannot start with numbers or contain spaces
