# 03 - Return Values

Learn how to get data back from functions using the `return` statement.

## Exercises

| File | Type | Description |
|------|------|-------------|
| `01_predict.py` | Predict | Basic return values and storing results |
| `02_predict.py` | Predict | Functions that return vs functions that print |
| `03_investigate.py` | Investigate | Analyze return values and variable scope |
| `04_modify.py` | Modify | Convert a print-based function into a return-based one |

## Key Concepts

- **`return`** - sends a value back to where the function was called
- **Return value** - the data that comes back from the function
- **`print()` vs `return`** - print displays output, return passes data back
- **Storing results** - assign return value to a variable for later use
- **`None`** - returned when a function has no return statement

## Help! My Code Doesn't Work!

Make sure that you check for the following things:
- Use `return` to send data back, not `print()` (unless you just want to display)
- Store the return value in a variable if you need to use it later
- A function stops executing after `return` is reached
- Functions without `return` (or with just `return`) return `None`
