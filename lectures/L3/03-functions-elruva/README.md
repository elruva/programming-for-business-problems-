# Session 3: Functions

Learn how to organize code into reusable functions, work with parameters and return values, and handle errors gracefully.

## Folders

| Folder | Topic | Description |
|--------|-------|-------------|
| `01_Function_Basics` | Function Basics | Define and call functions, execution order |
| `02_Parameters` | Parameters | Pass data to functions with arguments |
| `03_Return_Values` | Return Values | Get data back from functions with `return` |
| `04_Modules` | Modules | Import and use Python's built-in modules |
| `05_Error_Handling` | Error Handling | Handle errors gracefully with `try`/`except` |
| `06_Make` | Combined | Apply all function concepts together |

Start with `01_Function_Basics` and work through the folders in order.
