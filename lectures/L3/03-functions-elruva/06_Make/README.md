# 06 - Make

Apply all function concepts to build complete programs from scratch.

## Exercises

| File | Type | Description |
|------|------|-------------|
| `01_make.py` | Make | Create a grade calculator with validation |
| `02_make.py` | Make | Build an investment calculator using multiple functions |

## Skills Combined

These exercises combine:
- **Function definition** with `def` and proper naming
- **Parameters** for passing data into functions
- **Return values** for getting data back
- **Modules** for additional functionality
- **Error handling** for robust input validation

## Tips

- Start simple, then add features one at a time
- Give functions descriptive names that explain what they do
- Each function should do one thing well
- Use `return` when you need the result elsewhere, `print()` when you just want to display
- Always validate user input in real programs
